# MMACC_LB1 — Исследование сложных систем методом экспертных оценок

Лабораторная работа №1 по дисциплине **«Математические методы анализа сложных систем» (ММАСС)**.

Программа реализует строгие математические методы обработки результатов экспертного опроса, построение бинарных отношений, вычисление расстояний Кемени, сведение к задаче о назначениях, полный перебор всех $n!$ перестановок и автоматическое формирование чистового отчёта в формате Microsoft Word (`.docx`).

Проект поддерживает **два независимых режима работы**:
1. **Автономный консольный режим (CLI)** — самостоятельное терминальное приложение с удобным меню, интерактивным вводом данных, строгой валидацией, аккуратными таблицами и аналитическими пояснениями. Не требует интернета, браузера, серверов и Node.js.
2. **Интерактивный Web-интерфейс (FastAPI + React + TypeScript)** — визуальная витрина с интерактивными тепловыми картами (Heatmaps), подсветкой перекрестий, графом сходства экспертов и графиками.

                     └────────────┬─────────────┘
                                  │
         ┌────────────────────────┼────────────────────────┐
         │                        │                        │
   ┌─────▼──────┐          ┌──────▼──────┐          ┌──────▼──────┐
   │  Консоль   │          │  Генератор  │          │   FastAPI   │ (опционально)
   │   (CLI)    │          │ отчёта Word │          │ (папка api) │

### Принципы изоляции:
- **Прямая зависимость `CLI → Core`:** консольное приложение не зависит от FastAPI, React, Node.js, npm или браузера.
- **Отказоустойчивость:** при отсутствии папок `frontend` и `api` консольная программа и генератор отчётов работают в полном объёме.
- **Математическая идентичность:** CLI, генератор отчётов и Web API вызывают одни и те же функции Python-ядра. Результаты вычислений совпадают на 100%.

## 🎯 Сценарии запуска программы

### Сценарий 1: Автономная работа в консоли (CLI)

Предназначен для защиты лабораторной работы и демонстрации в терминале. Требуется только Python и библиотека `pandas`.

```powershell
# Запуск со стандартным файлом input.txt:
python -m expert_estimate.algorithm

# Запуск с указанием произвольного файла:
python -m expert_estimate.algorithm input_v2.txt
```

#### Главное интерактивное меню CLI:
```text
╔══════════════════════════════════════════════════════════════════════════════╗
║        ИССЛЕДОВАНИЕ СЛОЖНЫХ СИСТЕМ МЕТОДОМ ЭКСПЕРТНЫХ ОЦЕНОК (ММАСС)         ║
╚══════════════════════════════════════════════════════════════════════════════╝
  Источник данных: input.txt  |  Экспертов: 5  |  Альтернатив: 5
────────────────────────────────────────────────────────────────────────────────
  1. Исходные суждения экспертов и матрица рангов
  2. Метод средних арифметических рангов
  3. Метод медианных рангов (робастная статистика)
  4. Бинарные отношения и расстояния Кемени (матрица D, суммы S_k)
  5. Векторы предпочтений π^(k) и матрица позиционных потерь
  6. Задача о назначениях (минимизация позиционных потерь Φ_Assign)
  7. Истинная медиана Кемени (полный перебор всех n! перестановок)
  8. Сводное сопоставление результатов всех методов
  9. Итоговая аналитическая интерпретация группового выбора
────────────────────────────────────────────────────────────────────────────────
  a. Выполнить полный расчёт (все этапы с аналитикой)
  i. Ввести новые данные экспертов с клавиатуры
  f. Загрузить данные из другого файла
  0. Завершить работу программы
────────────────────────────────────────────────────────────────────────────────
```

#### Возможности консольной версии:
- **`1` – `9`** — пошаговый просмотр любого этапа с аккуратными Unicode-таблицами и пояснениями.
- **`a`** — сквозное выполнение всей цепочки лабораторной работы от исходных данных до итоговой аналитики.
- **`i`** — интерактивный ввод суждений экспертов с клавиатуры. Система подсказывает допустимые обозначения, проверяет отсутствие пропусков и дубликатов, предлагает сохранить введённые данные в файл или сразу запустить расчёт.
- **`f`** — мгновенное переключение на другой файл с данными без перезапуска программы.
- **`0`** — безопасный выход.

### Сценарий 2: Автоматическая сборка чистового отчёта Word (.docx)

В репозиторий встроен динамический генератор отчёта по ГОСТу:

```powershell
python build_docx_report.py
```

- Скрипт считывает активные суждения из `input.txt` (любой размерности $m \times n$).
- Вызывает математическое ядро и строит **все 10 обязательных таблиц** лабораторной работы:
  1. Исходные суждения экспертов;
  2. Матрица рангов «Эксперт × Объект»;
  3. Средние арифметические ранги и связки;
  4. Медианные ранги с вариационными рядами;
  5. Матрицы бинарных отношений $A_1 \dots A_m$ (моноширинный вид);
  6. Матрица расстояний Кемени $D$ и суммы строк $S_k$ с выделением медианных экспертов;
  7. Векторы предпочтений $\pi^{(k)}$;
  8. Позиционная матрица потерь $r_{ij}$ с пошаговым ручным расчётом ячейки $r_{1,1}$;
  9. Матрица оптимальных назначений $X$ задачи о назначениях;
  10. Сводное сопоставление всех методов.
- Формирует математические формулы, сравнительный анализ, аналитическое заключение и приложение с актуальным исходным кодом.
- Результат сохраняется в файл: **`Лабораторная_работа_1_Экспертные_оценки.docx`**.

## 📐 Математические особенности и разграничение критериев

В проекте строго разграничены две разные оптимизационные задачи:

1. **Задача о назначениях (позиционная матрица потерь):**
   $$\Phi_{\text{Assign}}(X) = \sum_{i=1}^n \sum_{j=1}^n r_{ij} X_{ij} \longrightarrow \min$$
   где $r_{ij} = \sum_{k=1}^m |(j - 1) - \pi_i^{(k)}|$.
   - Для текущего варианта `input.txt` (5 экспертов, 5 альтернатив): $\min \Phi_{\text{Assign}} = \mathbf{30}$.
   - Решение: $a_1 \succ a_2 \succ a_5 \succ a_3 \succ a_4$ (расстояние Кемени этого порядка равно $40$).

2. **Истинная медиана Кемени (полный перебор всех $n!$ перестановок):**
   $$\Phi_{\text{Kemeny}}(R) = \sum_{k=1}^m d(R, R_k) \longrightarrow \min$$
   - Для текущего варианта `input.txt`: $\min \Phi_{\text{Kemeny}} = \mathbf{38}$.
   - Глобальный оптимум: $a_1 \succ a_2 \succ a_3 \succ a_5 \succ a_4$.

> [!IMPORTANT]
> Значения **30** и **38** получены минимизацией принципиально разных функций. Решение задачи о назначениях ставит $a_5 \succ a_3$, а истинная медиана Кемени — $a_3 \succ a_5$, обеспечивая строго меньшее расстояние Кемени ($38 < 40$). Программа наглядно демонстрирует, что позиционная задача о назначениях не гарантирует глобального оптимума Кемени.

3. **Расстояние Кемени и число инверсий:**
   $$d(A, B) = \sum_{i=1}^n \sum_{j=1}^n |a_{ij} - b_{ij}| = 2 \cdot I(A, B)$$
   где $I(A, B)$ — число пар альтернатив с несовпадающим порядком (инверсий). Диагональ $a_{ii} = 1$ не даёт вклада, а каждая несогласованная пара учитывается дважды ($+1$ в ячейке $(i, j)$ и $+1$ в $(j, i)$).

## 📂 Формат входных данных

Входной файл (по умолчанию `input.txt`) содержит строки индивидуальных суждений экспертов (от лучшего к худшему через пробел):

```text
a2 a5 a1 a3 a4
a1 a3 a5 a2 a4
a3 a4 a5 a1 a2
a1 a2 a5 a3 a4
a4 a2 a3 a1 a5
```

### Как изменить вариант:
1. Отредактируйте `input.txt` в блокноте или редакторе кода.
2. Либо запустите CLI и нажмите **`i`** для пошагового ввода с клавиатуры.
3. Либо сохраните файл с другим именем (например, `variant_2.txt`) и вызовите:
   ```powershell
   python -m expert_estimate.algorithm variant_2.txt
   python build_docx_report.py variant_2.txt
   ```
