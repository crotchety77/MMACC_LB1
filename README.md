# MMACC_LB1 — Исследование сложных систем методом экспертных оценок

Лабораторная работа №1 по дисциплине **«Математические методы анализа сложных систем» (ММАСС)**.

Программа реализует математические алгоритмы обработки результатов экспертного опроса, построение бинарных отношений, вычисление расстояний Кемени и нахождение итоговых ранжирований.

Проект поддерживает **два независимых режима работы**:
1. **Автономный консольный режим (CLI)** — классическое терминальное приложение для демонстрации преподавателю. Не требует интернета, браузера, серверов и Node.js.
2. **Интерактивный Web-интерфейс (FastAPI + React + TypeScript)** — современная визуальная витрина с интерактивными тепловыми картами (Heatmaps), графом сходства экспертов и графиками.

---

## 🏛 Архитектурный принцип независимости

Web-интерфейс является **исключительно внешней опциональной надстройкой** над проверенным математическим ядром:

```text
                     ┌──────────────────────────┐
                     │       Python Core        │
                     │ (пакет expert_estimate)  │
                     │                          │
                     │  - transform.py          │
                     │  - stats.py              │
                     │  - relations.py          │
                     │  - kemeny.py             │
                     │  - named_matrix.py       │
                     │  - printers.py           │
                     │  - io.py                 │
                     │  - config.py             │
                     └────────────┬─────────────┘
                                  │
                     ┌────────────┴────────────┐
                     │                         │
               ┌─────▼──────┐           ┌──────▼──────┐
               │  Консоль   │           │   FastAPI   │  (опционально)
               │   (CLI)    │           │ (папка api) │
               │algorithm.py│           └──────┬──────┘
               └────────────┘                  │
                                         ┌─────▼─────┐
                                         │   React   │  (опционально)
                                         │ (frontend)│
                                         └───────────┘
```

### Принципы изоляции:
- **Цепочка `CLI → Core` прямая:** CLI не зависит от FastAPI, React, Node.js, npm или браузера.
- **Отказоустойчивость:** если папка `frontend` или `api` отсутствует, CLI продолжает работать в полном объёме.
- **Математическая идентичность:** и CLI, и Web API обращаются к одним и тем же функциям Python-ядра. Результаты расчётов идентичны на 100% (`CLI Result == API Result`).

## 🎯 Сценарии запуска программы

### Сценарий 1: Базовый запуск в терминале (CLI для сдачи преподавателю)

Этот сценарий предназначен для быстрой демонстрации работы в консоли. Требуется только Python и библиотека `pandas`.

```powershell
# Запуск со стандартным файлом input.txt:
python -m expert_estimate.algorithm

# Запуск с указанием конкретного файла:
python -m expert_estimate.algorithm input_v2.txt
```

#### Навигация в интерактивном меню CLI:
```text
=== Выбор вывода ===

Файл: input.txt   (экспертов: 6, объектов: 5)
--------------------------------------------------
   1. Исходные данные
   2. Матрица Эксперт × Объект
   3. Ранжирование по среднему
   4. Ранжирование по медиане
   5. Векторы предпочтений π^(k)
   6. Матрицы бинарных отношений
   7. Матрица расстояний Кемени
   8. Матрицы разностей |A − B|
   9. Медиана Кемени (среди экспертов)
  10. Медиана Кемени (задача о назначениях)
  11. Медиана Кемени (полный перебор)
  12. Сравнение подходов к медиане
   0. Выход
   a. Все этапы (рекомендуется для формирования отчёта)
   f. Сменить входной файл
```

- Чтобы вывести **все таблицы и матрицы сразу**, введите **`a`**.
- Чтобы выйти, введите **`0`**.

### Сценарий 2: Расширенная демонстрация через Web UI (FastAPI + React)

Включает интерактивный дашборд, динамические тепловые карты (Heatmap) с подсветкой перекрестья строк и столбцов, визуальный редактор ранжирований и граф близости экспертов.

#### Шаг А. Запуск Backend API (FastAPI)
Из корня проекта:
```powershell
python -m api
```
*(или `uvicorn api.main:app --reload --port 8000`)*

- Сервер запустится на адресе: `http://127.0.0.1:8000`
- Документация API (Swagger UI): `http://127.0.0.1:8000/docs`
- Собранный фронтенд также сразу доступен по адресу `http://127.0.0.1:8000/`.

#### Шаг Б. Запуск Frontend в режиме разработки (если требуется редактировать UI)
В отдельном терминале:
```powershell
cd frontend
npm install
npm run dev
```
- Откройте браузер по адресу: `http://localhost:5173`

## 📂 Формат входных данных и выбор варианта

Входные данные представляют собой текстовый файл (по умолчанию `input.txt`):
- Каждая строка соответствует ранжировке **одного эксперта**.
- Объекты перечисляются через пробел от лучшего к худшему (например, `a5 a1 a2 a3 a4`).

**Пример `input.txt` (6 экспертов, 5 объектов):**
```text
a5 a1 a2 a3 a4
a4 a3 a2 a1 a5
a3 a5 a4 a2 a1
a3 a4 a5 a1 a2
a5 a1 a2 a3 a4
a4 a2 a5 a1 a3
```

### Как подставить свой вариант:
1. Отредактируйте файл `input.txt`, вставив строки вашего варианта задания.
2. Либо создайте отдельный файл (например, `variant_5.txt`) и запустите:
   ```powershell
   python -m expert_estimate.algorithm variant_5.txt
   ```
3. Либо в Web-интерфейсе используйте вкладку **«Визуальный редактор»** или кнопку **«Загрузить .txt файл»**.

## 🧪 Автоматическая верификация и тесты

Для проверки того, что результаты API в точности равны результатам вычислений CLI/Core, включён тестовый набор:

```powershell
python -m unittest tests/test_api_vs_cli.py
```

Тест автоматически прогоняет оба варианта данных (`input.txt` и `input_v2.txt`), сверяя:
- Ранжирование по среднему и медиане;
- Все элементы матриц расстояний Кемени;
- Решения задачи о назначениях;
- Точные глобальные оптимумы Кемени полного перебора;
- Множества пересечений решений.
