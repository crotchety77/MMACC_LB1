# MMACC_LB1 — Исследование сложных систем методом экспертных оценок

Лабораторная работа №1 по дисциплине **«Математические методы анализа сложных систем» (ММАСС)**.

Программа предназначена для автоматизированной обработки результатов экспертного опроса, построения матриц отношений и нахождения итоговых ранжирований различными математическими методами в соответствии с требованиями лабораторной работы.

---

## 📌 Реализованные методы и возможности

1. **Метод средних арифметических рангов** — упорядочение объектов по возрастанию среднего ранга.
2. **Метод медианных рангов** — ранжирование объектов по медианным значениям оценок экспертов.
3. **Медиана Кемени** вычисляется тремя подходами:
   - **Среди экспертов** — поиск наилучшей ранжировки среди предложенных самими экспертами (на основе матрицы попарных расстояний Кемени).
   - **Через задачу о назначениях** — построение матрицы потерь $r_{ij}$ на основе векторов предпочтений $\pi^{(k)}$ и нахождение оптимальных назначений объектов на ранги.
   - **Полный перебор (Brute-force)** — точный глобальный поиск медианы на множестве всех возможных перестановок ($n!$).
4. **Сравнение подходов** — сопоставление результатов и проверка пересечения множеств оптимумов.
5. **Все необходимые матрицы для отчёта:**
   - Таблица исходных данных и матрица «Эксперт × Объект»
   - Векторы предпочтений $\pi^{(k)}$
   - Матрицы бинарных отношений для каждого эксперта
   - Матрица расстояний Кемени между экспертами ($D$)
   - Матрицы попарных разностей $|A_i - A_j|$
   - Матрица потерь $r_{ij}$

## 🚀 Установка и запуск

### Шаг 1. Установка Python (если ещё не установлен)

Если на вашем компьютере не установлен Python:

#### Для Windows:
1. Перейдите на официальный сайт [python.org/downloads](https://www.python.org/downloads/) и скачайте актуальную версию **Python 3.11+** (например, Python 3.13).
   - *Или установите через терминал:*
     ```powershell
     winget install Python.Python.3.13
     ```
2. **Важно при установке вручную:** в первом окне установщика обязательно отметьте галочку:
   > ☑ **Add python.exe to PATH** (Добавить Python в переменные среды PATH)
3. Нажмите **Install Now**.
4. После установки откройте новый терминал (PowerShell или командную строку) и проверьте:
   ```powershell
   python --version
   ```
   Должна отобразиться версия, например `Python 3.13.3`.

#### Для macOS:
```bash
brew install python
```

#### Для Linux (Ubuntu/Debian):
```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv
```

## 📂 Формат входных данных и выбор варианта

Входные данные представляют собой текстовый файл (по умолчанию `input.txt`), в котором:
- Каждая строка соответствует ранжировке **одного эксперта**.
- Объекты перечисляются в порядке убывания предпочтения эксперта (первый — наилучший).
- Префикс объектов по умолчанию — буква `a` (`a1`, `a2`, ..., `a5`).

**Пример `input.txt` (6 экспертов, 5 объектов):**
```text
a5 a1 a2 a3 a4
a4 a3 a2 a1 a5
a3 a5 a4 a2 a1
a3 a4 a5 a1 a2
a5 a1 a2 a3 a4
a4 a2 a5 a1 a3
```

### Как запустить со своим вариантом задания:
1. Замените содержимое файла `input.txt` строками своего варианта.
2. **Либо** создайте свой файл (например, `variant_2.txt`) и передайте его аргументом:
   ```powershell
   python -m expert_estimate.algorithm variant_2.txt
   ```
3. **Либо** во время работы программы введите `f` в меню и укажите путь к файлу.

## 🖥 Интерактивное меню программы

После запуска отображается интерактивное меню:

```text
=== Выбор вывода ===

Файл: input.txt   (экспертов: 6, объектов: 5)
--------------------------------------------------
   1. Исходные данные
   2. Матрица Эксперт × Объект
   3. Ранжирование по среднему
   4. Ранжирование по медиане
   5. Векторы предпочтений π^(k)
   6. Матрицы бинарных отношений
   7. Матрица расстояний Кемени
   8. Матрицы разностей |A − B|
   9. Медиана Кемени (среди экспертов)
  10. Медиана Кемени (задача о назначениях)
  11. Медиана Кемени (полный перебор)
  12. Сравнение подходов к медиане
   0. Выход
   a. Все этапы
   f. Сменить файл
```

- Чтобы получить **все данные, таблицы и матрицы сразу** (для копирования в отчёт), введите **`a`**.
- Можно вводить номера конкретных этапов через пробел или запятую, например: `3 4 9 12`.
