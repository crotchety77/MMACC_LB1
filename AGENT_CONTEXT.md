2. **Диагностика кода возврата 1 при запуске этапа 9**:
   - Установлено, что запуск вне штатного `main()` (например, через `python -c "..."` или в окружениях без принудительного UTF-8) в Windows завершался с кодом 1 из-за исключения `UnicodeEncodeError: 'charmap' codec can't encode characters in position ...: character maps to <undefined>`. В Windows консоли по умолчанию используется кодировка cp1251, которая не может вывести символы рамок Unicode (`═`, `┌` и т.д.) и отношение предпочтения (`≻`). В точке входа `main()` функция `sys.stdout.reconfigure(encoding="utf-8")` настроена, поэтому при стандартном запуске приложения CLI работает корректно.
