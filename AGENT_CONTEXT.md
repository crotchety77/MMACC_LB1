# AGENT_CONTEXT.md

## Текущее состояние проекта

### Задача
Интеграция канонического венгерского алгоритма (алгоритма Куна — Манкреса) на чистом Python в качестве основного решателя задачи о назначениях ($O(n^3)$), с сохранением полного перебора ($O(n!)$) в качестве независимого проверочного механизма и поиска всех альтернативных оптимумов.

### Выполненные действия
1. **Реализация венгерского метода (`expert_estimate/hungarian.py`)**:
   - Реализован алгоритм Куна — Манкреса с модификацией дуальных потенциалов на чистом Python без сторонних библиотек.
   - Сложность $O(n^3)$, поддержка квадратных матриц произвольного размера, точное целочисленное приведение без потери точности.
2. **Интеграция в модуль оптимизации (`expert_estimate/kemeny.py`)**:
   - `solve_assignment_hungarian`: точное решение задачи о назначениях венгерским методом за $O(n^3)$.
   - `solve_assignment_bruteforce`: независимый проверочный механизм на основе полного перебора $n!$ перестановок.
   - `solve_assignment` и `get_all_assignment_optima`: венгерский метод установлен в качестве основного решателя, перебор выполняет кросс-валидацию минимума и поиск всех ничьих (если их несколько, решение венгерского метода ставится во главу списка).
   - `get_kemeny_median_assignment`: строит матрицу назначений $X$ на основе решения венгерского метода.
3. **Обновление интерфейсов и отчётности**:
   - `expert_estimate/printers.py`: пункт 6 CLI явно отображает применение венгерского алгоритма ($O(n^3)$), верификацию перебором ($n! = 120$) и подтверждение совпадения результатов ($\Phi_{\text{Assign}} = 30$).
   - `expert_estimate/algorithm.py`: пункт 6 меню обновлён с указанием венгерского метода.
   - `build_docx_report.py`: обновлены теоретический (1.7) и практический (3.6) разделы отчёта, путь `BASE_DIR` приведён к динамическому `Path(__file__).resolve().parent`.
4. **Тестирование и верификация (`tests/test_hungarian.py` и `tests/test_api_vs_cli.py`)**:
   - Проверены данные варианта 6 (`input.txt`): потери $\Phi_{\text{Assign}} = 30$, назначение $a_1 \to 1, a_2 \to 2, a_5 \to 3, a_3 \to 4, a_4 \to 5$ ($a_1 \succ a_2 \succ a_5 \succ a_3 \succ a_4$).
   - Проверены данные варианта 2 (`input_v2.txt`): потери 24, полное совпадение алгоритмов.
   - Проверены случаи с множественными оптимумами (ничьими): венгерский алгоритм находит оптимальное базисное решение, перебор находит все альтернативы, венгерское решение гарантированно входит в их число.
   - Проверены 50 случайных матриц различного размера против полного перебора.
   - Все 9 тестов проекта успешно пройдены: `Ran 9 tests in 0.087s, OK`.
   - Проверено сквозное выполнение CLI (этапы 1–9) и генерация `Лабораторная_работа_1_Экспертные_оценки.docx`.
